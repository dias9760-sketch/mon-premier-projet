# Prospection : petites entreprises présentes sur les réseaux sociaux

Pour les entreprises qui n'ont pas de site web mais une page Facebook, Instagram ou TikTok. Elles n'ont pas encore de fiche : le message les invite à créer leur compte et à ajouter leur entreprise (bouton « Ajouter ou revendiquer mon entreprise »).

Remplacez ce qui est entre [crochets].

---

## Conseils

- **Personnalisez la première phrase :** citez un produit ou une publication récente de leur page. Un message qui montre que vous les connaissez reçoit beaucoup plus de réponses qu'un message copié-collé.
- **Envoyez depuis la page Bonszahé** (Facebook ou Instagram), pas depuis un compte personnel : c'est plus crédible.
- **Fiches sans site web :** pour l'instant, mettez le lien de la page Facebook ou Instagram dans le champ « Site web » de la fiche.
- **Une relance maximum**, 5 à 7 jours après, en une phrase : « Je me permets de revenir vers vous, souhaitez-vous que je crée votre fiche ? ».
