# Zarahissi — programme d'influenceuses IA

Deux influenceuses IA créées avec **Higgsfield** (images/vidéos) et pilotées par
**Claude** (stratégie, scripts, légendes, prompts) pour promouvoir les bijoux et
accessoires Zarahissi.

| | Nayla | Imani |
|---|---|---|
| Origine | Mayotte | Comores (Moroni) |
| Style | Chic, tradition, chiromani, or fin | Streetwear, fun, chaînes, perles, cauris |
| Plateformes | Instagram, Pinterest | TikTok, Reels, Snapchat |
| Fiche | [influenceurs/nayla.md](influenceurs/nayla.md) | [influenceurs/imani.md](influenceurs/imani.md) |
| Job Higgsfield | `cc1c1317-64e1-457f-b620-aed2379f39af` | `51817b9c-0a60-478d-a038-b28bd8f93c65` |

## Fonctionnement (chaque semaine)

1. **Planifier avec Claude** — collez [prompts/claude-generateur-contenu.md](prompts/claude-generateur-contenu.md)
   avec les produits de la semaine → calendrier, légendes, scripts et prompts Higgsfield.
2. **Photos produits** — importez les photos de vos bijoux dans Higgsfield (Media Upload).
3. **Générer les visuels** dans Higgsfield en utilisant **toujours la fiche personnage**
   comme référence (pour garder le même visage) + la photo du bijou :
   - images : *Generate Image* (prompt fourni par Claude)
   - vidéos : *Generate Video* / *Genjutsu* à partir de la fiche personnage
   - publicités UGC : *Marketing Studio* / *Ads Studio* avec le produit
4. **Valider** — vérifier que le bijou est fidèle au vrai produit (forme, couleur).
5. **Publier** — étiquette « contenu IA » activée, lien boutique en bio, code promo
   par influenceuse (ex. `NAYLA10`, `IMANI10`) pour mesurer les ventes.
6. **Mesurer** — chaque fin de mois, donnez à Claude les statistiques (vues, clics,
   ventes par code) pour ajuster le plan.

## Bonnes pratiques
- Transparence : indiquer que les influenceuses sont virtuelles (mention « Image virtuelle » obligatoire
  en France pour les images générées par IA à usage commercial, loi du 9 juin 2023).
- Cohérence : même visage, même voix, même univers à chaque publication.
- Budget : le plan gratuit Higgsfield limite à 1 génération à la fois et à 10 crédits ;
  un abonnement sera nécessaire pour un rythme quotidien en vidéo.
