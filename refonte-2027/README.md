## Voir les maquettes

- Images : `maquettes/images/direction-A.png`, `direction-B.png`, `direction-C.png`
- Version web : ouvrir `maquettes/direction.html?d=A` (ou `B`, `C`) dans un navigateur.

Chaque planche montre l'accueil sur ordinateur, l'accueil sur mobile, une fiche produit mobile avec le configurateur de personnalisation, ainsi que la palette, les typographies et les composants.

> Les visuels de bijoux sont des illustrations provisoires. Dans le prototype, elles seront remplacées par tes vraies photos produits (ou par des photos de démonstration).
